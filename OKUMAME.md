Bir Masal, Bin Hayal

Programlamaya Giriş dersi için hazırladığım, sekiz Türk masalını içeren dijital masal arşivi.

Web sitesi HTML, CSS ve JavaScript kullanılarak geliştirilmiştir. Masal arama, kategori filtreleme, masallar arasında gezinme ve yazı boyutu ayarlama özellikleri bulunmaktadır.

Web sitesi: https://yarenatila.github.io/bir-masal-bin-hayal/
